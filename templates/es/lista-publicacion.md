# Lista para publicación coordinada: [reporte o aviso]

## Registro técnico

- [ ] El resumen público refleja el impacto confirmado y sus límites.
- [ ] Las versiones afectadas y corregidas coinciden con las versiones publicadas.
- [ ] El proyecto ha aprobado los detalles técnicos que se harán públicos.
- [ ] Los enlaces apuntan al aviso y a la versión o corrección final.

## Atribución

- [ ] La cuenta de GitHub acreditada es correcta.
- [ ] El tipo de crédito refleja la contribución real.
- [ ] El investigador ha aceptado el crédito de GitHub, si recibió invitación.
- [ ] El agradecimiento escrito usa el nombre público acordado.

## Momento y comunicación

- [ ] La fecha de publicación está coordinada con el proyecto.
- [ ] No se exponen antes de tiempo el aviso privado, adjuntos o credenciales.
- [ ] El correo de contacto para seguimiento está actualizado.
- [ ] Los registros públicos se actualizan después de publicar el aviso original.

Esta lista es una ayuda de coordinación. Se aplica la política del proyecto y cualquier embargo acordado.
