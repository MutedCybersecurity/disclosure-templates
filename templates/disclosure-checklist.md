# Coordinated publication checklist: [report or advisory ID]

## Technical record

- [ ] The published summary reflects the confirmed impact and its limits.
- [ ] Affected and fixed versions match released artifacts.
- [ ] Public reproduction details are approved by the maintainer.
- [ ] Links point to the final advisory and release or patch.

## Attribution

- [ ] The credited GitHub account is correct.
- [ ] The credit type reflects the actual contribution.
- [ ] The reporter has accepted the GitHub credit, if invited.
- [ ] Any textual acknowledgement uses the agreed public name.

## Timing and communication

- [ ] Publication timing is agreed with the maintainer.
- [ ] No private advisory text, attachments, or credentials are exposed prematurely.
- [ ] The contact address for follow-up is current.
- [ ] Public records are updated only after the upstream advisory is published.

This checklist is a coordination aid. Follow the affected project's policy and any agreed embargo.
